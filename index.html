Featured · Engineering tool

Wire Harness Calculator

Picks the right wire gauge for every part on a harness BOM. For each part it finds the thinnest wire that carries the current (corrected for ambient temperature), keeps voltage drop within your limit over the run length, and fits every terminal listed for that part. When no gauge passes all three, it flags the part and says what to change. It runs as a command-line tool and as a browser app that runs the same Python code through Pyodide, so there's no server to host.

3checks per wire: current, drop, terminal fit
2interfaces: command line and web
